# Niko Polis

Public identity site for [Niko Polis](https://nikon0it.github.io/).

## Publishing boundary

This repository is intentionally public and contains only approved public copy and web-ready derivatives. Personal photo libraries, source media, drafts, analytics exports, credentials, and tokens belong in the private `niko-social-engine` workflow and must never be committed here.

## Verified public facts used

- Name: Niko Polis
- Region: New Jersey
- Employer: Microsoft
- LinkedIn: <https://www.linkedin.com/in/nikos-polis>
- Twitch: <https://www.twitch.tv/nikon0it>
- GitHub: <https://github.com/nikon0iT>

The site avoids unverified job titles, certifications, awards, client claims, testimonials, follower counts, or health credentials.

## Search setup

- Canonical URL, Open Graph metadata, and `Person` JSON-LD are in `index.html`.
- `robots.txt` and `sitemap.xml` are published at the site root.
- Add future verified profiles to both the visible Connect section and the JSON-LD `sameAs` array.
- Update `sitemap.xml` when adding durable public pages.
